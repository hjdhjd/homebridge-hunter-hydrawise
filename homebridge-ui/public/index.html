Welcome to homebridge-hunter-hydrawise. To get started:

  1. Ensure you have a Hydrawise account.
  2. Generate a Hydrawise API key, should you need one, from the account details section of the Hydrawise site and enter it below.
API key

Your API key is all this plugin needs to discover your controllers and run your zones.

About this API's limits
  • A limit of 3 API calls to start, stop, or suspend any zone within a 30 second interval.
  • An additional limit across the entire API of no more than 30 calls in any 5 minute period.
  • Suspending every zone is an account-wide action, and so is lifting it: a resume also clears the suspension on any individual zone.
Enhanced features · optional

Signing in with your Hydrawise account adds accurate rain and suspension state for every zone, a suspend switch for each individual zone, the full zone and controller names your account carries, whether each controller is reachable, and each controller's real model and firmware.

Your login is stored in the Homebridge configuration on this server. This part of the Hydrawise API is unofficial, so the plugin asks little of it and treats what it returns as a bonus: leave these blank and everything else still runs on the API key alone.

About this API's limits
  • Hydrawise publishes no limits for this API, so the plugin sets its own and stays well inside them.
  • The account details refresh every 15 minutes.
  • Zone suspensions are capped at 10 commands an hour. A command the plugin holds back puts its switch straight back where it was and says why in the Homebridge log.
  • This API suspends and resumes an individual zone, which is what the per-zone suspend switches run on.

To optimize performance and responsiveness, make this plugin a child bridge once you've completed configuration.

Notes
Things to keep in mind regarding the Hydrawise API:
  • The Hydrawise API is rate-limited with the following constraints:
    • A limit of 3 API calls to start, stop, or suspend any zone within a 30 second interval.
    • An additional limit across the entire API of no more than 30 calls in any 5 minute period.
  • Suspending every zone is an account-wide action, and so is lifting it: a resume also clears the suspension on any individual zone. With account credentials configured, an individual zone can be suspended and resumed on its own.
